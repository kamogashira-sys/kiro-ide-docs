# Agent Focus Mode（実験的機能）

**チャットを画面の中心に据えた、エージェント前提のレイアウトです。1.0 で導入されました。**

- **一次情報**: [Agent Focus Mode](https://kiro.dev/docs/experimental/focus-mode/)（公式ページ更新日: 2026-06-25）・[Dockable chat](https://kiro.dev/docs/chat/chat-in-editor/)・[Export sessions](https://kiro.dev/docs/chat/chat-export/)
- **導入バージョン**: **1.0**（2026-06-25）
- **位置づけ**: **実験的機能**（公式の `Experimental features` セクションに分類）

> ⚠️ **実験的機能です。** 公式の説明では「フィードバックに応じて洗練が続けられているプレビュー機能」です。
> 仕様が変わる可能性があります。

> **これは何か**: **従来のレイアウトをひっくり返します。** 会話がメインパネルを占め、
> セッションが左に並び、spec と差分が右の補助パネルに現れます。
> **コードを直接編集するのではなく、エージェントを指揮する**画面です。

---

## 1. 誰のための機能か

公式の説明:

> **エージェント的に働く開発者**のために設計されています。1行ずつコードを書くのではなく、**会話を通じて意図を定義する**人です。
> セッションを始め、やりたいことを説明し、構造が必要なら spec を紐づけ、エージェントに実行させます。

**Autopilot と Supervised の両モードが使えます**（[04_autopilot-supervised.md](04_autopilot-supervised.md)）。

---

## 2. レイアウト（3パネル）

| パネル | 位置 | 役割 |
|-------|------|------|
| **Sessions** | **左** | エージェントセッションの起動・移動・監視 |
| **Chat** | **中央** | **主要な操作面**（サイドバーより広い） |
| **Auxiliary** | **右** | spec・コードの差分・成果物（**必要になるまで隠れている**） |

---

## 3. 画面の切り替え

**IDE 右上の Agent Focus ボタン**でいつでも切り替えられます。

| 操作 | 結果 |
|------|------|
| ボタンを押す | 現在のセッションを Agent Focus Mode に移す |
| もう一度押す | **Editor View**（従来の画面）に戻る |

| 項目 | 挙動 |
|------|------|
| 同時実行 | **両方の画面を同時に動かせる** |
| 作業の継続 | **一方で始めた作業は他方でも続く** |
| セッション | **両者の間で引き継がれる** |

チャットをエディタタブとして開く **Dockable chat** からも移動できます（[02_chat.md](02_chat.md#11-dockable-chatチャットをエディタタブで開く)）。

---

## 4. 新しいセッションを始める

Agent Focus Mode で新しいセッションを作るとき、**任意でワークフローを選べます**。

| ワークフロー | 内容 |
|-----------|------|
| **Spec** | 構造化された機能開発 |
| **Plan** | **アイデアを実装計画に分解する。変更は行わない** |
| **Bug Fix** | 構造化されたバグ修正のワークフロー（調査・診断・解決） |
| **Quick Spec** | 高速な spec ワークフロー（明確化した後、要件・設計・タスクを自動生成） |

**ワークフローを選ぶと、そのセッションのエージェントモードが決まります。** ピッカーを飛ばして、直接入力してフリーフォームのチャットセッションを始めることもできます。

> **Plan は「変更を行わない」**のが特徴です。実装せずに計画だけ立てさせたいときに使います。
> Spec / Bug Fix / Quick Spec は [01_specs.md](01_specs.md) のワークフローに対応します。
> これらはエージェントセレクタの **Built-in** グループにも現れます（[07_custom-agents.md](07_custom-agents.md#61-出自でグループ分けされる)）。

## 5. 複数セッションの並列実行

**複数のエージェントセッションを起動し、それぞれが別のタスクやワークスペースで独立に動きます。** セッションは左パネルで**ワークスペースごとにグループ分け**され、状態が表示されます。

| 状態表示 | 意味 |
|---------|------|
| **Spinning**（回転） | **エージェントが作業中** |
| **Warning**（警告） | **エージェントが入力を待っている**（ツールの承認・明確化） |
| **Paused**（一時停止） | セッションはアイドルで、次のメッセージを待っている |

セッションをクリックすると、中央と右のパネルがその会話に切り替わります。**終わったセッションは一覧から消せます。**

> **Warning の状態が要点です。** 並列に走らせていると、どのセッションが自分の応答を待っているのかが
> 分からなくなります。状態表示がそれを示します。

## 6. チャットから spec が生まれる（Chat-first specs）

Agent Focus Mode では、**spec が会話から自然に生まれます**。フォームを埋めたりフェーズを手で順に進めたりする代わりに:

| 順 | 内容 |
|----|------|
| 1 | チャットセッションを始めてアイデアを説明する |
| 2 | **エージェントが意図を理解するために明確化の質問をする** |
| 3 | 準備ができたら **spec を紐づける**。エージェントが**話し合った内容を要件・設計・タスクに形式化する** |
| 4 | 実行を開始し、**セッションをまたいで進捗を監視する** |

**「まず話して、固まったら形式化する」**という進め方ができます。Editor View の spec が「フェーズを順に進める」のに対し、こちらは「会話が先」です。

---

## 7. Editor View との違い（公式の比較）

| 観点 | **Editor View** | **Agent Focus Mode** |
|------|---------------|--------------------|
| **主要な面** | コードエディタ | **チャット** |
| **ファイル編集** | **直接** | **エージェント経由** |
| **セッション** | **前面に1つ** | **複数を並列** |
| **spec** | **フェーズを順に** | **会話的、その後に形式化** |

---

## 8. Agent Focus にまだ無いもの（重要）

**一部の機能は IDE の画面（Editor View）が必要です。** Agent Focus からは戻る経路が用意されています。

| 機能 |
|------|
| **設定と環境設定** |
| **[Powers](../02_update/02_changelog-0x.md#powers) と [Skills](../04_reference/01_kiro-directory.md#7-agent-skills--kiroskills名前skillmd)** |
| **MCP サーバの管理** |
| **ターミナルへのアクセス** |
| **完全な git ワークフロー** |
| **ファイルの直接編集** |

**MCP サーバの設定やターミナル作業をするときは Editor View に戻る**必要があります。Agent Focus だけで一日を過ごせるわけではない、という前提で使ってください。

## 9. 1.0 の新 UI 群（関連機能）

Agent Focus Mode は 1.0 で加わった UI 変更の1つです。関連する2つの機能も同時に入りました。

### 9.1 Dockable chat（チャットをエディタタブで開く）

任意のチャットセッションを**ソースファイルと同じ幅のエディタタブ**として開けます。分割・ドッキング・自由な配置ができます。

**エディタタブとサイドパネルは同じセッションを表示し**、どちらから送ってもエージェントに届きます。詳細は [02_chat.md](02_chat.md#11-dockable-chatチャットをエディタタブで開く) を参照してください。

### 9.2 Export sessions（セッションの書き出し）

会話全体を**可搬な zip ファイル**として保存できます（`session.json`・`messages.jsonl`・`sub-executions/*.jsonl`）。

**書き出しは読み取り専用**で、Kiro に読み込み直すことはできません。詳細は [02_chat.md](02_chat.md#102-zip-で書き出すexport-chat) を参照してください。

---

## 10. 使いどころのまとめ

| 状況 | 推奨 |
|------|------|
| 複数のタスクを並列にエージェントに任せたい | **Agent Focus Mode** |
| まず会話して、固まってから spec にしたい | **Agent Focus Mode**（chat-first specs） |
| 自分でコードを書く・ターミナルを使う・MCP を設定する | **Editor View** |
| 長いコード生成をソースと並べて確認したい | **Editor View ＋ Dockable chat** |

**両方を同時に動かせる**ので、排他的に選ぶ必要はありません。
