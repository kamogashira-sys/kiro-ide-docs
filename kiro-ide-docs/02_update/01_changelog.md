## 🎉 1.0.0（GA）

**リリース日**: 2026-06-25
**公式ページ**: <https://kiro.dev/changelog/ide/1-0/>

Kiro IDE の一般提供（GA）版です。**エージェントがアクセスできる範囲を利用者が制御できるようにし**、専用エージェントを作って切り替えられるようにしたうえで、並列エージェントを指揮するための実験的な画面（Agent Focus）を導入しました。あわせて自然言語によるフック作成・チャットタブのドッキング・セッションのエクスポートが加わっています。

> **0.x から更新する方へ**: 1.0 では**フックの形式が v1 JSON に変わり、manual hooks が廃止**されています。
> セッションの移行も必要です。移行手順は [1.0 移行ガイド](03_migration-to-1.0.md) を参照してください。

### Agent Focus（実験的機能）

チャットを中心に据えた画面レイアウトで、複数のエージェントを指揮できます。1日の大半をエージェントの誘導に費やす開発者向けの設計です。

- セッションを**独立・並列に**実行し、状態を一覧で把握できる
- ファイルの変更はインラインの差分として表示される
- 構造化ワークフロー（Spec・Plan・Bug Fix・Quick Spec）から始めることも、自由形式のチャットから始めることもできる
- 画面右上から Agent Focus と従来の IDE を相互に切り替えられ、**どちらの方向にも作業が引き継がれる**

### Permissions（権限）

エージェントに何を許可し、何を禁止するかを明示的に定義できます。

- **capability ベースの権限システム**が、ファイル読み取り・コマンド実行・MCP 呼び出しのすべてをルールに照らして評価する
- 事前承認していない操作については IDE が同意を求める
- 同意の判断は**ワークスペース単位またはグローバル単位のルールとして永続化**できる
- 開始時に設定は不要（既定値が適用され、同意判断を重ねるにつれてポリシーが育つ）

> 詳細は [権限（Permissions）](../01_features/03_permissions.md)、値の一覧は [権限リファレンス](../04_reference/03_permissions.md) を参照してください。
> Kiro CLI 版の対応ページは [Permissions（CLI v3）](https://kiro.dev/docs/cli/v3/permissions) です。

### Custom Agents（カスタムエージェント）

専用エージェントを短時間で構築できます。

- **Markdown ファイルを書く**だけで作成できる
- ツールアクセスはタグ（`read`・`write`・`shell`・`web`）で宣言する
- MCP サーバーと権限ルールをファイル内にインラインで埋め込める
- バージョン管理でチームに共有できる
- 保存した瞬間にセレクターへ現れる
- **会話履歴を失わずにセッション中でエージェントを切り替えられる**

> Kiro CLI 版の対応ページは [Agent configuration（CLI v3）](https://kiro.dev/docs/cli/v3/agent-config) です。

### Hooks（フック）

自動化したい内容を自然言語で説明すると、Kiro がフックの設定を生成します。

- フックは **`.kiro/hooks/` に置かれる構造化された v1 JSON 形式**
- トリガーはファイルイベント・ツール使用のインターセプト・Spec タスク・プロンプト送信
- **0.x のレガシーフックは Agent Hooks パネルから直接移行できる**
- **manual hooks は manual steering ファイルに置き換えられた**

> Kiro CLI 版の対応ページは [Hooks](https://kiro.dev/docs/hooks/) です。
> **CLI の非 v3 のフックはまったく別の仕組み**（標準入力の JSON によるライフサイクルフック）なので混同しないでください。

### Dockable Chat（チャットのドッキング）

任意のチャットセッションを全幅のエディタタブとして開けます。長い会話を読み返すときに画面を広く使えます。

- チャットタブを右クリックして **Open in Editor** を選ぶとドッキングされる
- ソースファイルと並べて水平・垂直に分割できる
- エディタグループ間でドラッグでき、マルチモニターで別画面にチャットを置くこともできる
- **エディタタブとパネルは同期する**（どちらから送っても同じセッションに届く）

### Agent Selection（エージェントの選択）

会話履歴を失わずに、チャットセッション内でエージェントを切り替えられます。

- セレクターはチャット入力バーのモデルピッカーの隣にある
- 1つの会話の中で Default → 自作のコードレビュアー → Spec モードのように移動できる
- **再起動をまたいで保持される既定エージェント**を設定でき、新しいセッションが常に希望の状態で始まる

## 🔹 1.0.52

**リリース日**: 2026-07-02
**公式ページ**: <https://kiro.dev/changelog/ide/1-0-52/>

長時間セッションで早すぎる要約や致命的なクラッシュを引き起こしていた**コンテキスト要約（compaction）の問題を解消**したリリースです。セッションの移行は利用者が起点となる操作に変わり、ファイルのチェックポイントが保持されるようになりました。フックはレガシー形式から自動移行されます。

### 改善

- **コンテキスト超過からの回復**: 長時間セッションが `Context limit exceeded` エラーでクラッシュしなくなった。多段の要約フォールバックにより会話を継続できる
- **ターミナルの再利用**: ターミナルが呼び出しごとに作成・破棄されるのではなく、エージェントのコマンドをまたいで維持される（ターミナルパネルのちらつきが解消）
- **チャット入力が有効なまま**: エージェントが権限確認の待ち状態にあるときやストリーミング中でも、入力してメッセージをキューに入れられる
- **必要になったタイミングでのセッション移行**: 旧形式のセッションを自分のタイミングで移行できる。ファイルのチェックポイントが保持されるため、移行後のセッションでも取り消しが機能する
- **フックの自動移行**: レガシーフックが有効化時に v1 JSON 形式へ移行される。ツリービューに状態が表示される。互換性のないシェルコマンドはスキップされる
- **プロジェクト外のファイルアクセスの同意**: ワークスペース外のファイルを読み書きする前にエージェントが確認するようになり、プロジェクトをまたぐアクセスが可視化された
- **Agent Focus Mode の設定**: Agent Focus Mode に設定ペインが追加され、プロジェクトの挙動・通知設定・セッションの扱いをカスタマイズできる。Add Project ダイアログで複数フォルダを一度に選べる
- **権限カードのツール名表示**: 権限確認のヘッダーにツール名が表示される。Powers のカードにはサーバー・ツール・引数も表示される
- **`toolCardView` 設定**: 新しい `kiroAgent.toolCardView` 設定で、チャット内のツール呼び出しカードを展開・折りたたみのどちらで表示するか指定できる
- **権限設定のパスピッカー**: パスピッカーにより、権限設定時に広範囲を一括拒否するルールを誤って作ることを防げる
- **MCP 接続エラーの可視化**: MCP サーバーへの接続失敗が通知として表示され、設定ファイルへのリンクが付く
- **サブエージェントの可視化**: サブエージェントのカード・応答・名前がリアルタイムでチャットに表示される
- **ウェルカムカルーセル**: 更新後に複数ページのウェルカム画面が表示され、新機能と使い始め方を案内する
- **タスクリストのストリーミング**: タスクリストパネルがターン終了時だけでなく、作業の進行に合わせてリアルタイムで更新される
- **ワークスペース検索の安定化**: 検索とインデックス作成のメモリ使用量が減り、大規模コードベースでのクラッシュが減少
- **コマンド実行の分離強化**: Windows と macOS で、パスの扱い・認証情報アクセスの制御・ネットワークプロキシの適用を厳格化

### 修正

**コンテキストと要約**

- 圧縮後のコンテキストにシステムプロンプトが混入する問題
- 早すぎる要約によりセッションが必要以上に早く要約される問題
- 要約がセッションのタイトルを上書きする問題
- 長時間セッションを再開したときにメッセージが重複する問題
- エージェントの応答が誤って分割され、会話中にエラーが発生する問題
- エージェントが明示的に要求した大きいファイルの読み取りが切り詰められる問題

**ターミナル**

- 実行が続いているにもかかわらず、30秒間出力がないとターミナルのコマンドが強制終了される問題（`npm install` などの長時間コマンドに影響）

**セッションと移行**

- セッション移行でワークスペースハッシュの不一致が生じ、無言で失敗する問題
- 移行が、再試行可能なエラーで失敗する代わりに劣化したセッションを無言で書き込む問題
- 移行したセッションが手動リロードまでサイドバーに現れない問題
- 移行時に欠落したタイムスタンプが補完されない問題
- 無関係なセッションについて Windows のワークスペースパスが誤って保存される問題

**コマンド実行（Windows・macOS）**

- Windows でエージェントのコマンドがユーザーのパッケージディレクトリ（`.m2`・`.gradle`・`.cargo` など）にアクセスできない問題
- Windows でエージェントが実行する Java/Maven・Python pip・Node.js の fetch コマンドが失敗する問題
- Windows でプロセス分離用のシステムリソースが枯渇したときにエージェントのコマンドが失敗する問題

**MCP と言語サーバー**

- MCP のタイムアウト設定の誤りが、利用者に見えるエラーなしで無言の失敗を引き起こす問題
- 設定が変わっていないのに、失敗した MCP サーバーがポーリングごとに再接続を試みる問題
- 一部の MCP ツールの応答がチャットで正しく描画されない問題
- 言語サーバーのバイナリが欠けている場合に、段階的な機能低下ではなくハードクラッシュになる問題

**モデルのルーティング**

- 長時間セッションが要約された後に、選択中のモデルが予期せず変わる問題

**フックと Steering**

- フックの移行に複合シェルコマンドが含まれてしまう問題
- Steering のルールについて、モデルが無視するのではなく注入されたルールに応答してしまう問題
- コロンを含む Steering のクエリが誤って分割され、`file:path` のような参照が壊れる問題
- 組み込み Steering の内容が欠落し、常時include の指定でも Included Steering カードが現れない問題
- `PreTaskExec` / `PostTaskExec` のフックイベントが発火しない問題

**権限と同意**

- ターンの途中でエージェントが停止したときに保留中の権限要求が消え、セッションの再開が必要になる問題
- Supervised モードでの権限承認が、同一ターン内の後続のツール呼び出しに適用されない問題
- セッションから離れると権限拒否の理由が消える問題
- パスピッカーがないために、広範囲を一括拒否するルールを誤って作りやすい問題
- `web_fetch` の権限確認が誤ったリソースを表示する問題
- 権限ポリシーの読み込みエラーが利用者に見えない問題

**UI とチャット**

- エージェントのストリーミング中にチャットの送信ボタンが無効になる問題
- 利用者のメッセージ内でコンテキスト参照タグがインライン描画されない問題
- エージェントのターンがツール呼び出しから始まったときに Kiro のアバターが表示されない問題
- セッションを再度開いた後にキャンセルボタンが動作しない問題
- 組み込み Steering のドキュメントをクリックすると `Unable to resolve resource` エラーが出る問題

**エージェントの挙動**

- ワークスペースを開いていない状態で Spec ワークフローがクラッシュする問題
- コードレンズの Run Task のクリックが一部の状況で動作しない問題
- タスク実行中に Spec が添付ドキュメントのコンテキストを失う問題
- タスクリストパネルが逐次更新されず、ターン終了時にしか結果を表示しない問題
- `read-file` が画像を適切に描画せずテキストとして渡す問題
- 通常でない空白文字を含むパスで `read-file` が失敗する問題
- `agentIgnoreFiles` 設定に不正な内容が入っているとクラッシュする問題

**Agent Focus Mode**

- セッションが削除または完了したときにキュー内のセッションが停止する問題
- セッションのないプロジェクトがビューに表示されない問題
- OS の通知が他のフローを妨げる問題
- Add Project で複数フォルダを選べない問題

## 🔹 1.0.89

**リリース日**: 2026-07-03
**公式ページ**: <https://kiro.dev/changelog/ide/1-0-89/>

性能改善と Agent Focus Mode の作り込みを中心としたリリースです。起動時にセッションが自動復元され、アイドル時のリソース消費が下がりました。前払いクレジットパックがアカウントダッシュボードに表示されるようになり、権限・フック・Steering がウィンドウやカスタムエージェントのプロファイルをまたいで正しく動作するよう修正されています。

### 改善

- **Agent Focus のセッション復元**: IDE を再度開いたときに、最後にアクティブだった Agent Focus Mode のセッションが復元される（手動で開き直す必要がない）
- **Agent Focus セッションの名称変更**: セッションレールから直接名前を変更できる
- **アイドル時の CPU 使用率の低下**: テレメトリ・バッテリー監視・ステータスバー更新が最適化され、アイドル時の背景リソース消費が減った
- **権限評価の高速化**: 許可・拒否ルールが多い利用者でも権限チェックが高速に動作する
- **より正確なコンテキスト使用量**: コンテキスト使用率が、固定の見積りではなくモデルの実際のウィンドウサイズを反映するようになった
- **前払いクレジットの IDE 内表示**: 組織の前払いクレジットパックが、残高と有効期限とともにアカウントダッシュボードに表示される（Kiro を離れずに消費を追える）
- **発火したフックのチャット表示**: フックが発火すると、ツール呼び出しの折りたたみにその名前が表示され、どのフックがなぜ動いたか分かる
- **カスタムエージェントのコマンドが即時反映**: `.kiro/agents/` のプロファイルを追加・変更すると、チャットのエージェントセレクターに即座に反映される（再起動不要）
- **モードピッカーの説明表示**: エージェントモードがモードセレクターに説明を表示するようになり、適切なモードを選びやすくなった
- **Spec タスクがモデル選択を尊重**: Spec ワークフローのタスクが固定モデルに既定せず、選択したモデルを使う
- **チャット内のターミナル出力の改善**: ターミナルの内容が構造化ブロックとしてチャットに埋め込まれ、複数行のコマンド結果が読みやすくなった
- **Run Command の信頼性**: 単独の Run Command アクションが、出力をバッファするコマンドで早期完了しなくなった
- **MCP の List 呼び出しのページング**: MCP クライアントが List 呼び出しをページングするようになり、多数のリソースやツールを公開するサーバーでもサイズ上限に達しない
- **エージェントプロファイルでのポリシーバンドル**: `read-shell`・`edit-workspace`・`dev-shell` などの組み込み権限プリセットをエージェントプロファイルから参照できる（個別ルールを一から書かなくてよい）
- **より安全な信頼設定の移行**: レガシー権限形式からのファイル読み書きの許可が自動移行されなくなった。代わりに `edit-workspace` プリセットでカバーされ、広すぎるルールの継承を防ぐ
- **thinking モードの既定値**: 拡張思考に対応するモデルで、既定で強制的に有効化されることがなくなった。モデルと effort の選択がそのまま尊重される

### 修正

**Supervised モードと権限**

- **より安全な MCP インストールと spec ホバー**: `kiro://` リンクから MCP サーバーをインストールする際、設定に書き込まれる前に確認ダイアログが表示され、コマンド・引数・環境変数またはヘッダー名（値は非表示）が示される。spec ファイルの内容はホバーツールチップ内でリテラルテキストとして描画され、信頼していないワークスペースでは spec ホバーにクリック可能なリンクが含まれない
- **Code OSS v1.109.5 へのアップグレード**: Code OSS v1.108.2 から v1.109.5 へ移行。ターミナルのスティッキースクロールは `terminal.integrated.stickyScroll.ignoredCommands` で特定のコマンドを対象外にできるようになり、`editorBracketMatch.foreground` で一致する括弧の色を変更できる。`terminal.integrated.allowInUntrustedWorkspace` で信頼していないワークスペースでもターミナルを使うことを選択できる
- **チャット履歴の一括移行**: **Migrate All** ボタンで、アップグレード前の未移行セッションをすべて一度の操作で移行できる（進捗もリアルタイム表示）。フィルタでまだ移行が必要な旧セッションだけに一覧を絞り込める
- **モデルエラーからのより安定した回復**: 応答のストリーミングが始まる前に発生した失敗は自動的に再試行されるようになった。ネットワークエラーもより正確に分類され、表示されるメッセージが実際に起きたことを反映する
- **実際に使っているシェルに合わせたコマンド**: エージェントが、OS の既定を仮定するのではなく、実際に実行しているシェル用のターミナルコマンドを書く
- **エディタが見ている内容で検索**: `grep_search` と `file_search` が IDE 自身の検索機能を経由するようになり、結果がエディタで見える内容と一致する
- **Spec ワークフローの check-in と探索**: Spec ワークフローがフェーズ間で check-in のために一時停止する。Spec セッションが Default エージェントと同じコードベース探索ツールを持つようになった
- **Quick Spec 完了後の次のアクション**: 完了メッセージが「必須タスクを実行」「必須・任意タスクを実行」「先に要件を分析」をリンクとして提示し、同じチャットセッション内で続行できる
- **リモートホストの信頼プロンプト**: リモートホストへの接続時、リモート拡張機能が実行される前に信頼するかどうかを確認する。**Trust and Connect**・**Don't Connect**・**Always trust this remote host**（マシン単位で記憶）の選択肢がある
- **Powers パネルにロード状態を表示**: インストール済み Powers の一覧に、各 power が実際にロードされたかどうか（ロードエラーや個々のコンポーネントの問題を含む）が表示され、パネルから Agent Plugin 自身の `mcp.json` を開ける
- **作業中も ignore ファイルが適用される**: `kiroAgent.agentIgnoreFiles` を編集すると、リロードなしで実行中のセッションに反映される。ignore ルールは読み取りだけでなく書き込みにも適用され、無効なエントリは黙って失敗せず表面化する
- **steering としての `AGENTS.md`**: steering ディレクトリに置いた `AGENTS.md` ファイルが、通常の steering として読み込まれるようになった
- **エージェントプロファイルでの CLI 形式フック**: カスタムエージェントプロファイルが、Kiro CLI 形式で書かれたフックを受け付けるようになった。Kiro CLI 用に作られたプロファイルが、フックを書き換えずに IDE でも読み込まれる
- **フックの動的な confirm オプション**: フックが、事前に宣言するだけでなく実行時に `confirmCommand` で confirm オプションを供給できるようになった
- **より明確なカスタムエージェントのエラー**: 要求されたエージェントが使用できない場合、Kiro が「見つからない」ではなく理由を示すようになった
- **MCP の失敗理由を表面化**: MCP サーバーの接続に失敗した場合、具体的な理由が MCP 出力チャンネルと MCP パネル内のサーバーのツールチップに表示されるようになった（単なる Connection Failed ではなくなった）
- **エクスプローラーからファイルをコンテキストとして選択**: エクスプローラーで1つ以上のファイルまたはフォルダを右クリックし、**Select Files as Context** を選ぶと、現在のチャットセッションにコンテキスト参照として追加できる
- **より明確なフック移行の文言**: 旧フックの移行を促すプロンプトが、「v1 へ移行」ではなく新しいフック形式への移行であることを案内するようになった

### 修正

**Terminal & Updates**

- 長い複数行コマンドが途中で切断され、ターミナルが `heredoc>` や `dquote>` の継続プロンプトで固着する問題
- コマンド終了後も孤立したシェルプロセスが残り続ける問題
- Windows updater が、実行中のコピーを更新せず別の場所に2つ目の Kiro をインストールする問題

**Chat & Agents**

- セッション中のエージェント切り替えが反映されず、前のエージェントが次のターンを処理し続ける問題
- ターンの停止がキャンセルではなくエラーとして報告される問題
- 失敗したターンのエラーメッセージが1回ではなく3回表示される問題
- エージェントの応答完了直後に送信したメッセージが、通知なく失われる問題
- カスタムエージェントプロファイルの名前が長い場合、spec タスクとサブエージェントの dispatch が `Invalid tool use format` で失敗する問題（エージェントは警告付きで短縮された名前で登録される）
- サブエージェントのツール呼び出しが途中で中断されると、回復せずに実行全体が失敗する問題

**Permissions**

- ワークスペース用に保存した Always Allow のルールが、以降のセッションで適用されない問題
- `--flag=value` 構文を使う PowerShell コマンドで Always Allow が永続化されない問題

**MCP & Steering**

- エージェントが Kiro の設定ディレクトリ外にある `mcp.json` を作成・編集できない問題
- カスタム MCP レジストリが名前空間付きサーバー名を拒否し、1件の不正な形式のエントリがレジストリ内の全サーバーを隠してしまう問題
- Steering パネルでスキルまたは自動追加対象の steering 文書をクリックしても、Windows では開かない問題

**Sign-in**

- 外部 IdP のセッションが期限切れになった後、Kiro がサインイン状態を維持したまま動作不能になる問題（サインインページに戻るようになった）

**Chat UI**

- Supervised モードの Review changes パネルが、変更ファイルの一覧を小さな固定領域に閉じ込め、領域に合わせて広がらない問題
- Chat ビューがアクティビティバーで自身のアイコンを表示しない問題
- MCP と Hooks のツリービューのボタンやアクションがテーマに従わない問題（アクションはリンクではなくボタンとして描画されるようになった）

**Agent Focus Mode**

- そのチャットを開いていないウィンドウから見たセッションで、権限プロンプトが自動的に閉じられる問題
- 復元されたマルチルートプロジェクトでスピナーが消え続ける問題、および `.code-workspace` ファイルを Open Existing Project が拒否する問題
- 開いたことのないセッションに未読バッジが表示される問題、およびセッションの要対応状態が静かに元に戻る問題
- バックグラウンドウィンドウが再接続できなかった復元済みプロジェクトで、スピナーが無限に表示され続ける問題（再度開くための行をクリックできるようになった）
- セッションへの接続が失われたウィンドウが無反応になり、セッションを選択すると空白のチャットになる問題
- Finder・Dock・Spotlight から Kiro を起動した場合に **Open with Kiro CLI** が表示されない問題、および Kiro CLI プロジェクトの行をクリックしてもターミナルウィンドウが前面化しない問題
- セッション行の並び順が時刻ラベルと一致しない問題、およびレールのタイトルが古い値を一瞬表示する問題

**Specs & Tools**

- バグを記述した spec がバグ修正フローに入らない問題、spec のナビゲーションリンクが1行で描画される問題、spec 分析中のクラッシュとメモリ増大の問題
- 一部のモデルで `todo_list` がスキーマエラーで失敗する問題

## 🔹 1.0.242

**リリース日**: 2026-07-28
**公式ページ**: <https://kiro.dev/changelog/ide/1-0-242/>

エディタのコンテキストメニューに Kiro のサブメニューが追加され、エラーや警告に対する `Ask Kiro to Fix` のクイックフィックスが使えるようになりました。フック作成用のフォームも加わっています。Code OSS は v1.108.2 に更新され、**IDE の表示言語で返答するようになりました**。

### 改善

- **エディタのコンテキストメニューのアクション**: ファイル内の選択範囲を右クリックすると Kiro のサブメニューが開く。**Ask Kiro** は選択範囲を添付した新しいサイドバーのセッションを開き、入力を待つ。**Fix Grammar / Spelling**・**Write Comments for this Code**・**Write a Docstring for this Code**・**Fix this Code**・**Optimize this Code** はワンクリックで実行される。各プロンプトは `kiroAgent.editorActions.prompts` 設定でカスタマイズできる
- **Ask Kiro to Fix**: 任意のエラーや警告の電球アイコンから `Ask Kiro to Fix` を選べる。編集可能なプロンプトと、該当行がコンテキストとして添付される。言語サーバー自身の修正候補の下に表示される
- **フック作成フォーム**: Agent Hooks ビューの `+` ボタンで **Create a hook** フォームが開き、フックを手作業で設定できる。ツリー内のフックをクリックするとエディタで開き、他の場所で元ファイルを編集すると開いているフォームが更新される
- **表示言語での返答**: Kiro が VS Code の表示言語を読み取り、その言語で返答する。**コード・API 名・ファイルパス・コマンド出力は翻訳されない**
- **Code OSS v1.108.2 へのアップグレード**: Code OSS v1.107.1 から v1.108.2 へ移行。ターミナルの IntelliSense（`terminal.integrated.suggest.enabled`）が上流の既定に合わせて既定で有効になった
- **Shift＋貼り付けでプレーンテキスト**: チャット入力での `Shift+Cmd+V`（Windows・Linux では `Shift+Ctrl+V`）が、リッチテキストと画像の処理を飛ばしてクリップボードの内容をプレーンテキストとして貼り付ける。通常の貼り付けは変わらない
- **より厳密なコマンド信頼パターン**: `GIT_PAGER=cat git diff` のように環境変数の代入で始まるコマンドに「常に許可」を選んだ場合、保存されるパターンが代入部分ではなく**実行されるプログラムに紐づく**ようになった。`env` を通して実行されたコマンドは完全一致のみで保存される
- **ファイル参照が未保存の編集を含む**: `#File` の参照と、エディタから送った選択範囲が、ディスク上の保存内容ではなく**現在のエディタの内容**を使うようになった（作業中の変更がエージェントに見える）
- **チャットでの Powers のツール呼び出し**: Powers の起動時に内容を表す card のタイトルが表示され、`list` と `configure` が空のカードではなく出力を表示する
- **セッションエクスポートがフォルダを記憶**: Export chat のダイアログが、毎回 Downloads に既定するのではなく最後にエクスポートしたフォルダで開く
- **コマンドのパスのツールチップ**: コマンドのツールカードで切り詰められたパスにカーソルを合わせると全体が表示される
- **`sleep` で承認を求めない**: `sleep` だけを呼ぶコマンドで、承認のためにセッションが止まらなくなった
- **到達できないページでの早期失敗**: `web_fetch` がクライアントエラーを返すページを再試行しなくなり、重複していた再試行も1回にまとめられた。リンク切れや応答しないホストは約30秒で適切に失敗する
- **レート制限時の賢い再試行**: サービスが待機を要求した場合、推測ではなくその待機時間に従うようになった（混雑時の回復がより予測しやすくなった）
- **Agent Focus Mode の Agent Settings**: 読み取り専用の Agent Settings ページに、そのプロジェクトに適用される Steering・MCP サーバー・フック・スキル・Powers が一覧表示され、それぞれに **Edit in IDE** のリンクが付く。プロジェクト単位のメニュー項目名が Kiro Settings から変更された
- **Kiro CLI で開く**: Agent Focus Mode の Add Project メニューから、ポップアウトしたターミナルの Kiro CLI にフォルダを渡せる。**Kiro CLI 2.8.1 より新しいバージョン**がインストールされている場合に表示される

### 修正

- 特定の拡張機能（SARIF Viewer など）がインストールされているとチャットが開始できず、エージェントから応答がない問題
- 2つの IDE ウィンドウが同時に保存済みトークンを書き込み、一時的に読めない状態になって有効なセッションが終了する予期しないサインアウト
- `2>&1` を含む `cmd` のコマンドで、信頼ダイアログがコマンドではなく `1` を表示し、さらに一致しない「常に許可」のルールを保存してしまう問題（Windows のみ）
- スラッシュコマンドと `#` のコンテキストピッカーのメニューで、Tab が強調表示中の項目を選択しない問題
- Chrome または Edge のアドレスバーからコピーした URL を貼り付けると、URL ではなくページタイトルが挿入される問題
- ツールの承認が保留中に後続のメッセージを送ると、会話の記憶がない状態でターンが始まり、エージェントが意図の確認を求めてくる問題
- 承認待ちで一時停止したセッションを閉じて開き直すと、Supervised モードが Review changes パネルを失い、受け入れも拒否もできない「Working」カードが残る問題
- Supervised モードの Review changes バーでファイル名をクリックしても、そのファイルの差分が開かない問題
- Agent Focus Mode のウィンドウで Spec ワークフローの質問に回答した後に停止する問題
- 回答済みの質問カードが、送信した回答ではなく質問だけを表示する問題（過去のセッションを開き直した場合は引き続き質問のみ表示される）
- Agent Focus Mode のウィンドウで、Steering・スキル・MCP のプロンプトピッカーが「No matching items」と表示する問題
- ワークスペース外のファイルに「Always Allow」を与えると `cannot open file:///consent` エラーで失敗する問題
- OAuth を必要とする MCP サーバーで、サインイン完了直後に abort エラーで失敗する問題
- 言語サーバーが問題を報告しているファイルについて、診断が断続的に「No diagnostics found」と報告する問題
- 長いシェルコマンドが、パネル内で折り返されずに承認プロンプトのヘッダーからあふれる問題
- `<script>` や `<iframe>` などの生の HTML を含むメッセージが、空のチャットバブルとして描画される問題（リテラルのテキストとして表示されるようになった）
- Spec の書式の問題に対する Ask Kiro のクイックフィックスが無言で失敗する問題
- サブエージェントの終了後に Spec ワークフローが診断を確認できず、Spec の書式の問題が修正されないままになる問題
