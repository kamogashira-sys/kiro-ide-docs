## 📏 記述の粒度

Kiro IDE のリリースは公式の情報量に幅があるため、次の4段階で書き分けています。

| 段階 | 対象 | 実測件数 | 本サイトでの書き方 |
|------|------|---------|-----------------|
| **系列** | マイナー系列のランディングページ | 12 | 機能ごとに節を設けて解説 |
| **専用ページ** | 専用ページを持つリリース | 11 | Improvements・Fixes を箇条書き |
| **詳細なパッチ** | 系列ページ内で Improvements/Fixes を持つパッチ | 15 | 専用ページと同じ箇条書き |
| **要約のパッチ** | 説明が1〜2文のパッチ | 30 | 表または短い節に公式の説明を記載 |

**公式が説明を公開しているものは省略せず掲載します。** 逆に、公式に記述のない内容は推測して書きません。

## 🔍 情報源と網羅性の担保

本セクションは次の一次情報のみを根拠にしています。

| 情報源 | 用途 |
|-------|------|
| [公式 changelog（IDE）](https://kiro.dev/changelog/ide/) の系列ページ | リリース内容・**日付の正**・パッチの全量 |
| 各リリースの専用ページ | Improvements・Fixes の詳細 |
| [公式 Atom フィード](https://kiro.dev/changelog/feed.atom) | 新リリースの速報検知 |

> **フィードだけに頼らない理由**: 公式 Atom フィードは直近25件のローリングウィンドウのため、
> **1.0.165（2026-07-16）が配信されていません**。本サイトは系列ページに埋め込まれたパッチ一覧の
> データも突き合わせ、取り落ちが起きないようにしています。

**日付の扱い**: 公式ページの表示日を正とし、ISO 形式（`YYYY-MM-DD`）に変換して記載します。
タイムゾーン変換は行いません。
